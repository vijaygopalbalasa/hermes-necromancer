## A fairer comparison, for honesty

When the task text spells out all four requirements, the same local model fixed the code in 4 of 5 runs
without the plugin and 4 of 5 with it, and it never claimed done with a failing test in either arm
(one run in each arm failed to finish, one of them on Hermes's own model connection timing out). So the plugin
earns its place when "done" is defined by tests the agent was not told about or did not read, as in the run above,
and when an agent is tempted to edit the tests. It does not make a model smarter.
